Android / Application Architecture

Arith-Matic

Educational software with a focus on modular design, maintainability, and accessibility.

Purpose

Arith-Matic is intended to provide structured mathematics practice through an Android application. Its architecture separates presentation, question generation, application state, and persistence.

Engineering Focus

A central design concern is keeping mathematical question generation independent of the user interface. This allows question types and rules to evolve without requiring the presentation layer to understand their internal details.

Accessibility is also a release requirement. The design accounts for screen-reader semantics, touch targets, readable contrast, adaptable text, and alternative input methods.

Technologies

  • Kotlin
  • Android and Jetpack Compose
  • ViewModel-based application structure
  • Modular question generation

C++ / Software Architecture

Minotaur

Exploring the organization and responsibilities of a custom game architecture.

Purpose

Minotaur is an experimental game-development project focused on building understandable and reusable systems.

Architectural Approach

The project uses an entity-component architecture, emphasizing composition and separation of responsibilities.

An important distinction is that the design is entity-component rather than a formal entity-component-system architecture. Components provide structure and behavior without requiring an ECS-style systems processing model.

Engineering Interests

  • Entity and component responsibilities
  • Composition versus inheritance
  • Modular game functionality
  • Maintainable C++ interfaces

C++ / High-Performance Computing

N-Body Simulation

Gravitational simulation using high-performance computing resources.

Purpose

The N-Body project explores computational simulation of gravitational interactions among multiple bodies.

Computing Environment

The simulation was written in C++ and executed through the Texas Advanced Computing Center (TACC).

Slurm was used to manage execution on the computing infrastructure, providing experience with batch-oriented workloads and remote computational resources.

Technical Areas

  • Numerical simulation
  • Computational performance
  • C++ programming
  • HPC job execution through Slurm

Kotlin / Mobile Game Development

SkyDiver

A mobile game project exploring gameplay objects and reusable systems.

Purpose

SkyDiver is an Android arcade game involving player movement, descending gameplay, collectibles, and obstacles.

Engineering Approach

The project separates common game-object behavior from specialized gameplay interactions.

Collectibles and obstacles manage their respective interaction behavior, while the player maintains state, movement, and gameplay controls.

Technical Areas

  • Kotlin and Android development
  • Object-oriented game architecture
  • Collision handling
  • Frame-time-based updates
